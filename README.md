# 道诡人生 · Daogui Life

基于《道诡异仙》世界观的文字模拟人生游戏。一念成道，一念成诡。

《道诡异仙》是狐尾的笔连载于起点中文网的长篇小说（2021.11 — 2023.05），融合中式克苏鲁、道教修仙与精神病叙事，讲述高中生李火旺同时存在于现代精神病院与大梁修仙世界，无法分辨哪边才是真实。

### 两界与迷惘

故事的核心悬念在于"真假"——李火旺在现代世界是精神病患者，在大傩世界是修道者，两边的身体同步运动。现代世界实为迷惘天道所构建，而大傩世界原为鬼界，经大傩改造而成。两个世界之上是白玉京——司命所居的神之都城，时间在此混乱交错，过去与未来并存。

### 心素·心浊·心蟠

- **心素**：先天体质，太始之前"质之始而未成体者"，体内有先天一炁，能力是"以假修真"——将所想之物修真出来。心素之人身体各部位皆是炼制法器的绝佳材料，被各方觊觎。心素是体质，不等同于心蟠。代表人物：李火旺（心素体质，同时也是季灾的心蟠，但二者是不同概念）。
- **心浊**：先天体质，与遗忘天道关联。心浊之人能令被遗忘之物从世间消失，随年龄增长能力愈强，最终连自身记忆、性别、年龄都会遗忘。头发可强化法器。代表人物：闻人诡。
- **心蟠**：司命的因缘，即司命的过去。如果说司命是巨树，心蟠就是种子。每位司命都有对应的心蟠，心蟠具备其天道的双面性质，最终会成长为（或被吞噬为）对应的司命。

### 司命与天道

司命是居于白玉京的神级存在，各掌一道或多道天道。主要司命：

| 司命 | 天道 | 说明 |
|------|------|------|
| 大傩 | 秩序 · 混乱 | 世界本身，最初的司命 |
| 季灾 | 迷惘 · 清醒 | 李火旺的最终形态，化为迷惘屏障抵御福生天 |
| 无生老母 | 慈悲 · 死亡 · 生长 | 白莲教信仰，心蟠为白灵淼 |
| 阴阳斗姥 | 真假 | 坐忘道信仰，成员以麻将牌为代号 |
| 巴虺 | 痛苦 | 袄景教信仰之一，通过苍蜣登阶以痛苦换力量 |
| 牯神 | 痛苦 | 袄景教信仰之一，吸收了部分巴虺之力 |
| 将相首 | 战争 | 兵家信仰，无形无念，哪里有冲突杀戮哪里就有祂 |
| 三清 | 秘密 | 心蟠为诸葛渊，窥见福生天全貌后陷入疯狂 |
| 五智如来 | 血肉 | 佛门背后的司命，正德寺祭拜血肉大佛 |

| 福生天 | 恐惧 · 未知 · 绝望 | 终极威胁，试图入侵白玉京 |

### 主要势力

- **坐忘道**：信奉阴阳斗姥的邪修组织。修行"坐忘论"，以欺骗获取力量。成员以麻将牌为代号，面容会化为对应牌面。领袖称"骰子"，上层为小四喜（东南西北风）与大三元（红中、白板、发财）。可通过罔天宝诰召唤斗姥化身。监天司正是为对抗坐忘道而设立。
- **监天司**：列国为应对天灾而设立的组织，创建者为上古人皇颛顼。地位超然，在超自然事务上有无限权限。由司天监统领，五位司天少监协助管理。内部等级为十天干（甲乙丙丁戊己庚辛壬癸），流通货币为阳寿丹。虽服务于皇室但不参与皇室内部斗争。
- **袄景教**：内部供奉巴虺与牯神，同一教派内的不同信仰侧重。修炼途径是"苍蜣登阶"——以极端自残和痛苦献祭换取巴虺赐力。传承法器为大千录。李火旺曾持大长老身份。
- **白莲教**：信奉无生老母的秘密结社，以白氏和连氏为核心家族。圣女可与无生老母直接沟通。教义核心："无生老母，真空家乡。"白灵淼为圣女，亦是无生老母的心蟠。
- **法教**：引入福生天外来司命（于儿神等）的危险教派，目标是协助外来司命入侵大傩世界，曾发动法教之乱侵占四齐。后被大梁监天司、白莲教等联合剿灭。

### 关键人物

- **李火旺**：主角，现代精神病患者/大傩世界修道者。心素体质，先后持有袄景教大长老、坐忘道红中、监天司司天监等身份，最终成为司命季灾，化为迷惘屏障守护世界。
- **白灵淼**：女主，白化病体质（白发红瞳），李火旺之妻。原为清风观药引子，后成为白莲教圣女。是无生老母的心蟠，最终与无生老母合一对抗福生天。
- **诸葛渊**："司命之下第一人"，持因果之目与心浊纺锤，三清（秘密天道）的心蟠。独身对抗斗姥而死，死后以幻象形式继续辅助李火旺。
- **丹阳子**：本名羊蛋子，清风观观主，不识字的邪修。以活人炼丹，强行收李火旺为徒。被坐忘道以伪经欺骗，后短暂成为司命。
- **静心师太**：本名陈红袖，安慈庵尼姑，腐烂司命（秽腐大觋）的心蟠。有一个叫徐儿的心素儿子。曾以人皮书等物助李火旺。因腐烂司命被季灾吞噬而受牵连死亡。

### 核心主题

小说取"坐忘"之意——摆脱身体束缚与聪明才智，与大道相通。故事论证的是：过度追求绝对真相只会导向疯狂（三清窥见福生天全貌后发疯），真正的智慧在于拥抱迷惘、守住人间情感。终极恐怖不是妖魔鬼怪，而是不可知的存在本身（福生天 = 恐惧/未知/绝望）。李火旺的胜利不靠力量，而是选择了迷惘与爱，而非宇宙级的清醒。

## 游戏简介

你将在道诡世界中开启一段全新的人生。抽取天赋、选择命运、经历世间百态，在修仙与疯狂的边缘行走。每一次轮回都是独一无二的故事。

游戏中所有事件均以大梁普通人视角叙述——你不会直接看到司命、白玉京等上层设定的全貌，只能从天地异象、坊间传闻中窥见端倪。

## 天赋系统

从十道天命中择三而行。天赋分为 **天命 · 仙品 · 珍品 · 良品 · 凡品 · 厄运** 六个稀有度，可无限刷新天赋池。

- 特殊天赋（心素、心浊、白化病）触发独立剧情线
- 每个天赋至少有 1 个专属剧情事件 + 年度被动效果
- 持有特定天赋时，部分已有事件会解锁专属选项
- 反面天赋暗含正面效果——祸福相依
- 部分天赋互斥，不可同时选择

## 数值系统

| 数值 | 作用 | 死亡条件 |
|------|------|----------|
| 神志 | 心素专属，归零迷失于两界之间 | ≤0（心素） |
| 修为 | 凡人→锻体→练气→筑基→金丹→元婴→化神→大乘→肉身司命→天人合一 | — |
| 金银 | 每年扣生活费（成年/门派/婚姻/子嗣叠加），影响体魄、修为、人脉，门控大量购买选项 | ≤-80 |
| 人脉 | 影响势力晋升速度、门控社交事件、影响事件频率 | — |
| 体魄 | 影响生存和战斗，过低拖累修为 | ≤0 |
| 悟性 | ≥60 时有概率每年自动增加修为 | — |
| 气运 | 影响事件品质和频率，触发福祸事件 | ≤-80（概率） |
| 因果 | >30 提升气运，<-30 拖累气运，门控部分势力入门 | ≤-90（概率） |
| 姻缘 | 未婚/有情人/已婚/子嗣 | — |

### 数值交互

属性之间相互影响：

- **金银→体魄**：贫困（<-20）营养不良掉体魄；富裕（>80）可获医疗加体魄
- **金银→修为**：富裕（>50）可购修炼资源；赤贫（<-20）有概率掉修为
- **金银→人脉**：大富（>100）自动涨人脉；极贫（<-50）自动掉人脉
- **人脉→晋升**：>20 降低门派晋升修为门槛；<-10 提高门槛
- **体魄→修为**：<20 有概率每年掉修为
- **因果↔气运**：善因果（>30）缓慢涨气运；恶因果（<-30）拖累气运
- **修为→体魄**：高修为减缓衰老速度
- **人脉→金银**：>30 有概率每年涨金银

## 地点系统

23 个地点，出生时随机分配，之后通过事件选项迁移（消耗旅费）。每个地点有独立视觉主题、音效氛围和地方故事。

赵家村 · 李家村 · 鲁城 · 阳城 · 大梁城 · 玉清山 · 边境 · 城外郊野 · 南疆 · 杏岛 · 鬼市 · 清风观遗址 · 上京城 · 四齐 · 安慈庵 · 正德寺 · 昆仑 · 白玉京 · 天陈 · 虚空 · 北疆 · 狐山 · 龙眠泽

切换地点时自动变更：
- CSS 主题（9 种：村庄/城市/山岳/邪修/鬼市/丛林/战场/仙境/虚空）
- Canvas 浮动符箓粒子（字符、颜色、透明度）
- Web Audio 音效氛围（节奏、滤波、旋律复杂度）

## 其他系统

- **心蟠**：门派晋升至高阶或满足特定剧情条件后可觉醒为司命的心蟠（斗姥/巴虺/无生老母/三清/蟠螭/于儿），与心素无关，获得对应天道被动效果和专属结局
- **婚恋**：16 岁后邂逅→相知→表白→成婚→子嗣，影响安静年份和结局
- **血肉法门**：18 岁后可接触五智如来修炼线（游戏原创）
- **跨世界**：通过道具/NPC 解锁大齐·天陈·龙脉剧情线
- **成就**：80 个成就，localStorage 跨轮回保存
- **轮回**：死后可保留一个天赋进入下一世
