# 道诡人生 · Daogui Life

基于《道诡异仙》世界观的文字模拟人生游戏。一念成道，一念成诡。

> **剧透警告**：以下内容涉及《道诡异仙》小说的核心设定与关键剧情走向。如果你尚未读完原作，建议先去阅读小说，体验会更好。

《道诡异仙》是狐尾的笔连载于起点中文网的长篇小说（2021.11 — 2023.05），融合中式克苏鲁、道教修仙与精神病叙事，讲述高中生李火旺同时存在于现代精神病院与大梁修仙世界，无法分辨哪边才是真实。

### 两界与迷惘

故事的核心悬念在于"真假"——李火旺在现代世界是精神病患者，在大傩世界是修道者，两边的身体同步运动。现代世界实为迷惘天道所构建，而大傩世界原为鬼界，经大傩改造而成。两个世界之上是白玉京——司命所居的神之都城，时间在此混乱交错，过去与未来并存。

### 心素·心浊·心蟠

- **心素**：先天体质，太始之前"质之始而未成体者"，体内有先天一炁，能力是"以假修真"——将所想之物修真出来。心素之人身体各部位皆是炼制法器的绝佳材料，被各方觊觎。心素是体质，不等同于心蟠。代表人物：李火旺（心素体质，同时也是季灾的心蟠，但二者是不同概念）。
- **心浊**：先天体质，与遗忘天道关联。心浊之人能令被遗忘之物从世间消失，随年龄增长能力愈强，最终连自身记忆、性别、年龄都会遗忘。头发可强化法器。代表人物：闻人诡。
- **心蟠**：司命的因缘，即司命的过去。如果说司命是巨树，心蟠就是种子。每位司命都有对应的心蟠，心蟠具备其天道的双面性质，最终会成长为（或被吞噬为）对应的司命。

### 司命与天道

司命是居于白玉京的神级存在，各掌一道或多道天道。主要司命：

| 司命 | 天道 | 说明 |
|------|------|------|
| 大傩 | — | 世界本身，最初的司命 |
| 季灾 | 迷惘 · 清醒 | 李火旺的最终形态，化为迷惘屏障抵御福生天 |
| 无生老母 | 慈悲 · 生长 · 死亡 | 白莲教信仰，心蟠为白灵淼 |
| 阴阳斗姥 | 真假 | 坐忘道信仰，成员以麻将牌为代号 |
| 巴虺 | 痛苦 | 袄景教信仰之一，通过苍蜣登阶以痛苦换力量 |
| 牯神 | 痛苦 | 袄景教信仰之一，吸收了部分巴虺之力 |
| 将相首 | 战争 | 原作中无明确心蟠对应 |

### 主要势力

- **坐忘道**：信奉阴阳斗姥的邪修组织。修行"坐忘论"，以欺骗获取力量。成员以麻将牌为代号，面容会化为对应牌面。领袖称"骰子"，上层为小四喜（东南西北风）与大三元（红中、白板、发财）。可通过罔天宝诰召唤斗姥化身。监天司正是为对抗坐忘道而设立。
- **监天司**：大梁朝廷的官方机构，专司监察天下异事、对抗邪修。地位超然，在超自然事务上有无限权限。由司天监统领。
- **袄景教**：内部供奉巴虺与牯神，同一教派内的不同信仰侧重。修炼途径是"苍蜣登阶"——以极端自残和痛苦献祭换取巴虺赐力。传承法器为大千录。李火旺曾持大长老身份。
- **白莲教**：信奉无生老母的秘密结社，以白氏和连氏为核心家族。圣女可与无生老母直接沟通。教义核心："无生老母，真空家乡。"白灵淼为圣女，亦是无生老母的心蟠。
- **法教**：引入福生天外来司命（于儿神等）的危险教派，目标是协助外来司命入侵大傩世界，代表了来自世界体系之外的存在性威胁。

### 关键人物

- **李火旺**：主角，现代精神病患者/大傩世界修道者。心素体质，先后持有袄景教大长老、坐忘道红中、监天司司天监等身份，最终成为司命季灾，化为迷惘屏障守护世界。
- **白灵淼**：女主，白化病体质（白发红瞳），李火旺之妻。原为清风观药引子，后成为白莲教圣女。是无生老母的心蟠，最终与无生老母合一对抗福生天。
- **诸葛渊**："司命之下第一人"，持因果之目与心浊纺锤，三清（秘密天道）的心蟠。独身对抗斗姥而死，死后以幻象形式继续辅助李火旺。
- **丹阳子**：本名羊蛋子，清风观观主，不识字的邪修。以活人炼丹，强行收李火旺为徒。被坐忘道以伪经欺骗，后短暂成为司命。
- **静心师太**：安慈庵尼姑，心素之子徐儿之母。曾以人皮书等物助李火旺。

### 核心主题

小说取"坐忘"之意——摆脱身体束缚与聪明才智，与大道相通。故事论证的是：过度追求绝对真相只会导向疯狂（三清窥见福生天全貌后发疯），真正的智慧在于拥抱迷惘、守住人间情感。终极恐怖不是妖魔鬼怪，而是不可知的存在本身（福生天 = 恐惧/未知/绝望）。李火旺的胜利不靠力量，而是选择了迷惘与爱，而非宇宙级的清醒。

## 游戏简介

你将在道诡世界中开启一段全新的人生。抽取天赋、选择命运、经历世间百态，在修仙与疯狂的边缘行走。每一次轮回都是独一无二的故事。

游戏中所有事件均以大梁普通人视角叙述——你不会直接看到司命、白玉京等上层设定的全貌，只能从天地异象、坊间传闻中窥见端倪。

## 核心玩法

### 天命抽取
- 从十道天命中择三而行，天赋分为 **天命 · 仙品 · 珍品 · 良品 · 凡品 · 厄运** 六个稀有度
- 可无限次刷新天赋池，直到满意为止
- 特殊天赋触发独特剧情线（心素、心浊、白化病）
- 每种天赋都有至少一个独立剧情事件
- 反面天赋暗含正面效果——祸福相依

### 数值系统

| 数值 | 说明 |
|------|------|
| 神志 | 心素专属，归零则迷失于两界之间 |
| 修为 | 境界：凡人 → 锻体 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘 → 肉身司命 → 天人合一 |
| 金银 | 过低会饿死，可用于游历和购买 |
| 人脉 | 影响事件选项和势力关系 |
| 体魄 | 影响生存和战斗 |
| 悟性 | 影响修炼速度和事件触发 |
| 气运 | 影响随机事件走向 |
| 因果 | 善恶因果，影响长期命运 |
| 姻缘 | 显示婚恋状态：未婚/有情人/已婚及子嗣 |

### 神志系统
- 只有 **心素** 体质才会受到神志(SAN)系统影响
- 普通角色不会疯狂，神志显示「稳固」
- 心素角色神志过低会触发视觉特效（画面抖动、色偏、文字错乱）

### 心蟠系统
- 心素角色可触发心蟠觉醒事件
- 原著心蟠：斗姥（真假天道）、巴虺（痛苦天道）、无生老母（慈悲天道）、三清（秘密天道）
- 游戏原创心蟠：蟠螭（秩序天道）、于儿（法教天道）
- 不同心蟠状态影响后续事件走向，对应不同司命的因缘

### 婚恋系统
- 16 岁后可邂逅心仪之人，男女角色有不同的初遇事件
- 经历初遇、相知、表白、成婚四个阶段，也可通过长辈介绍直接成婚
- 婚后可孕育子嗣（最多两个孩子），触发家庭生活事件
- 伴侣遇险、孩子展现天赋、老年相伴等多条家庭剧情线
- 已婚状态影响安静年份描述和最终结局
- 婚姻与子嗣在面板中实时显示

### 血肉天道系统【游戏原创】
- 18 岁后可接触五智如来（血肉天道司命）的修炼法门
- 原作中五智如来掌血肉天道，正德寺祭拜血肉大佛，靠血肉献祭获取力量
- 游戏中扩展为独立剧情线，包含发现法门、修炼、深入、终局等阶段
- 深入修炼可获得强大的感知力，但代价是精神和因果的损耗
- 最终需选择：斩断联系、成为使徒、或以人间情爱对抗天道
- 注：原作无"欢喜禅/双修"设定，此为游戏原创玩法

### 散修系统
- 脱离门派后自动成为散修，享受独行路线事件
- 叛出多个门派会触发叛门余波事件（追杀、功法冲突、经脉崩溃等）
- 散修有独立的修炼加成和专属成就线

### 跨世界系统（大齐·天陈·龙脉）
- 需通过特定道具或 NPC 接触解锁跨世界剧情，不可直接触发
- **大齐线**：听闻大齐传说 → 获得龙脉碎片 → 幽都梦境 → 遇见诸葛渊残魂 → 联络高智坚
- **天陈线**：发现天陈古玉 → 目睹左丘咏降临 → 天陈入侵与白灵淼危机
- **龙脉线**：理解龙脉体系 → 龙脉崩裂危机 → 高智坚登基续接龙脉 → 三重历史交汇
- 关键道具：龙脉碎片、时辰沙漏、天陈古玉、大齐金符（均有独立事件链）
- 关键 NPC：诸葛渊（残魂）、高智坚（龙脉之血）、左丘咏（生长天道·肉身司命）
- 时间线与原作吻合：诸葛渊死后以残魂出现，高智坚在龙脉危机时登基，天陈入侵与白莲教保卫战同步

### 事件特色
- **NPC 记忆**：遇到的 NPC 会记住好感度、初遇年龄，后续事件中再次出现
- **事件标记**：早期事件会设置 flag，影响后续剧情走向
- **前后呼应**：有恩报恩、有仇报仇、30 年河东 30 年河西
- **道具联动**：持有特定道具可改变事件结局
- **普通人视角**：所有事件以大梁普通人视角叙述，不直接描写司命、白玉京内部

```bash
# Python

npx serve .
```

然后访问 `http://localhost:8080`
