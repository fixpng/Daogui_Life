# 道诡人生 (Daogui Life)

一个基于《道诡异仙》世界观的文字模拟游戏。

## 设定参考

- **世界观**: 修仙世界 vs 精神病院的真假模糊
- **核心种族**: 心素、心浊、坐忘道、普通人、修奴、镖师等
- **势力**: 青丘、大梁、南疆、大傩等
- **时间线**: 主角李火旺出生前~结局后

## 核心玩法

1. **开局随机**
   - 天赋：心素/心浊/坐忘道/普通人/修奴/镖师等
   - 出身：青丘/大梁/南疆/大傩等
   - 年份：随机时间节点

2. **每年自动推进**
   - 每年自动触发随机事件
   - 关键事件需要选择
   - 数值影响结局

3. **数值系统**
   - 神志：越低越容易看到"真实"
   - 修为：境界从凡人到大傩
   - 财富/人脉/寿命等
