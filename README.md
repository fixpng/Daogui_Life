# 道诡人生 · Daogui Life

基于《道诡异仙》世界观的文字模拟人生游戏。一念成道，一念成诡。

## 游戏简介

你将在道诡世界中开启一段全新的人生。抽取天赋、选择命运、经历世间百态，在修仙与疯狂的边缘行走。每一次轮回都是独一无二的故事。

## 核心玩法

### 天命抽取
- 从十道天命中择三而行，天赋分为 **天命 · 仙品 · 珍品 · 良品 · 凡品 · 厄运** 六个稀有度
- 可无限次刷新天赋池，直到满意为止
- 特殊天赋触发独特剧情线（心素、心浊、白化病）
- 每种天赋都有至少一个独立剧情事件
- 反面天赋暗含正面效果——祸福相依

### 数值系统

| 数值 | 说明 |
|------|------|
| 神志 | 心素专属，归零则迷失于两界之间 |
| 修为 | 境界：凡人 → 锻体 → 练气 → 筑基 → 金丹 → 元婴 → 化神 → 大乘 → 大傩 → 造化 |
| 金银 | 过低会饿死，可用于游历和购买 |
| 人脉 | 影响事件选项和势力关系 |
| 体魄 | 影响生存和战斗 |
| 悟性 | 影响修炼速度和事件触发 |
| 气运 | 影响随机事件走向 |
| 因果 | 善恶因果，影响长期命运 |

### 神志系统
- 只有 **心素** 体质才会受到神志(SAN)系统影响
- 普通角色不会疯狂，神志显示「稳固」
- 心素角色神志过低会触发视觉特效（画面抖动、色偏、文字错乱）

### 心蟠系统
- 心素角色可触发心蟠觉醒事件
- 六种心蟠状态：济在、斗姥、巴虺、无生、蟠螭、鱼儿
- 不同心蟠状态影响后续事件走向

### 古人系统
- 抽到 **古人** 天赋将出生于 200~2000 年前的远古时代
- 独有远古纪元：混沌初开 → 万仙大战 → 上古仙朝 → 百家争道 → 仙道衰微
- 远古专属事件：万仙大战余波、上古大能指点、远古传送阵、昆仑秘境等
- 远古灵气充沛，每年额外修为加成

## 道具系统

78 件道具，按稀有度分五级，掉率逐级递减：

| 稀有度 | 数量 | 掉率 | 说明 |
|--------|------|------|------|
| 普通 (Common) | 10 | 35% | 常见法器、丹药 |
| 稀有 (Uncommon) | 14 | 12% | 有一定来历的器物 |
| 珍贵 (Rare) | 28 | 5% | 名门法器、珍稀丹药 |
| 史诗 (Epic) | 15 | 1% | 独立支线剧情 |
| 传说 (Legendary) | 11 | 0.2% | 独立支线剧情 |

- 已拥有的道具不会重复获取
- 史诗和传说级道具均有独立支线剧情
- 持有特定道具可改变事件结局（itemBonus 系统）

### 事件特色
- **NPC 记忆**：遇到的 NPC 会记住好感度、初遇年龄，后续事件中再次出现
- **事件标记**：早期事件会设置 flag，影响后续剧情走向
- **前后呼应**：有恩报恩、有仇报仇、30 年河东 30 年河西
- **道具联动**：持有特定道具可改变事件结局
- **普通人视角**：所有事件均以大梁普通人视角叙述，不直接描写司命、白玉京等上层设定

- 心素角色神志下降时音效加剧
- 事件出现时伴有锣鸣/叮声
- 默认静音，点击右上角 ♪ 开启

## 运行方式

直接用浏览器打开 `index.html`，或启动本地服务器：

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`
