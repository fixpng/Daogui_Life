# 道诡人生 (Daogui Life)

基于《道诡异仙》世界观的文字模拟游戏。一念成道，一念成诡。

## 游戏简介

你将在道诡世界中开启一段全新的人生。抽取天赋、选择命运、经历世间百态，在修仙与疯狂的边缘行走。每一次轮回都是独一无二的故事。

## 核心玩法

### 天命抽取
- 从十道天命中择三而行，天赋分为 **天命·仙品·珍品·良品·凡品·厄运** 六个稀有度
- 可无限次刷新天赋池，直到满意为止
- 特殊天赋触发独特剧情线（心素、古人等）
- 反面天赋暗含正面效果——祸福相依

### 神志系统
- 只有 **心素** 体质才会受到神志(SAN)系统影响
- 普通角色不会疯狂，神志显示「稳固」
- 心素角色神志过低会触发视觉特效（画面抖动、色偏、文字错乱）

### 古人系统
- 抽到 **古人** 天赋将出生于 200~2000 年前的远古时代
- 独有远古纪元：混沌初开 → 万仙大战 → 上古仙朝 → 百家争道 → 仙道衰微
- 8个远古专属事件：万仙大战余波、上古大能指点、远古传送阵、昆仑秘境等
- 远古灵气充沛，每年额外修为加成

### 数值系统
| 数值 | 说明 |
|------|------|
| 神志 | 心素专属，归零则迷失于两界之间 |
| 修为 | 境界：凡人→锻体→练气→筑基→金丹→元婴→化神→大乘→大傩→造化 |
| 金银 | 过低会饿死，可用于游历和购买 |
| 人脉 | 影响事件选项和势力关系 |

### 势力加入
坐忘道 · 监天司 · 袄景教 · 白莲教 · 镖局 · 法教 —— 每个势力有独立事件线

### 游历系统
12岁后可花费金银前往不同地点，各地有独特事件和危险度

### 物品收集
法器、丹药、符箓、经书等 10 种可收集物品，影响属性

### 成就系统
20个成就，包括反面天赋专属成就（草根崛起、白手起家、久病成医等）

### 音效系统
- Web Audio API 生成的暗黑氛围音效
- 低频无人机式底噪 + 风声呼吸纹理
- 心素角色神志下降时音效加剧
- 事件出现时伴有锣鸣/叮声
- 默认静音，点击右上角 ♪ 开启

## 设定参考

- **世界观**: 修仙世界 vs 精神病院的真假模糊
- **核心概念**: 心素（可感知两界）、坐忘道、黑太岁、白玉京
- **势力**: 坐忘道、监天司、袄景教、白莲教、法教、镖局
- **关键NPC**: 李火旺、白灵淼、诸葛渊、太清真人
- **时间线**: 远古混沌初开 → 万仙大战 → 上古仙朝 → 大梁年间 → 末法时代

## 运行方式

直接用浏览器打开 `index.html`，或启动本地服务器：

```bash
# Python
python3 -m http.server 8080

# Node.js
npx serve .
```

然后访问 `http://localhost:8080`

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架依赖
- Google Fonts: Ma Shan Zheng、ZCOOL XiaoWei、Noto Serif SC
- Canvas 粒子系统
- Web Audio API 音频合成
- localStorage 持久化成就和轮回次数
